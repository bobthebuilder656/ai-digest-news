  8. 08 · InfoWorld

    AWS unveils local emulator service to help enterprises accelerate app development and testing

    AWS launched a new local emulator service for its cloud services on Wednesday to help enterprises accelerate application development and testing. The service, named AWS Emulator, will allow developers and AI coding agents to build, deploy, and test AWS-dependent applications on their machines without provisioning actual cloud infrastructure and paying for it, thereby potentially reducing development time and associated costs, the hyperscaler said in a statement. To achieve this, AWS Emulator replicates the APIs of AWS services locally and exposes a local HTTP endpoint that the AWS Command Line Interface (CLI), software development kits (SDKs), and coding agents can access using the same APIs they use to interact with the cloud, it added. Developers can redirect these tools to the local endpoint by setting the AWS_ENDPOINT_URL environment variable, allowing existing application code and tests to run against simulated AWS services without modification, it further said.

    Reinforcement Learning

    Reinforcement learning is a training method where an AI learns by trial and error: it takes an action, and gets rewarded or penalized depending on the outcome. It's essentially how you'd train a dog with treats, the dog doesn't understand English instructions, but it learns "sit" earns a treat and jumping on the guest doesn't, purely from repeated feedback. It's used both in robotics, like a robot learning to walk, and in shaping how chatbots respond to people.
