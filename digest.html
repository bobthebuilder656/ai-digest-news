  13. Today's Term

    One new AI word a day, explained simply — it adds up.

    Open-Weight Model

    An open-weight model is one whose trained internal parameters are published for anyone to download and run themselves, as opposed to a "closed" model only accessible by paying to send requests to a company's servers. It's the difference between being handed the actual recipe and ingredients to cook a dish yourself at home, versus only being able to order that dish from the restaurant. Open weights don't necessarily mean the training data or code used to build the model is public too.
