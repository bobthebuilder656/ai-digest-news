    One new AI word a day, explained simply — it adds up.

    Deep Learning

    Deep learning is machine learning using neural networks with many layers stacked on top of each other, rather than just one or two. Each extra layer lets the network build on what the previous one learned, similar to how a first layer might notice edges in a photo, the next layer combines edges into shapes, and a later layer combines shapes into "this is a face." That extra depth is what made today's boom in image recognition, speech, and language possible.
