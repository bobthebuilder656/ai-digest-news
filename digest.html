    PuppyGraph adds AI schema builder and MCP support to help ease enterprise agent adoption

    PuppyGraph on Tuesday said it was adding an AI-assisted graph schema builder and MCP integrations to PuppyGraph 1.0, the new version of its distributed graph query engine for enterprise data. The update is designed to help developers reduce the complexity, latency, and costs associated with letting AI agents query interconnected data across thousands of database tables and multiple platforms. The AI-assisted schema builder automatically maps existing tables into graph entities, relationships, and properties, allowing developers to review and approve the resulting schema rather than manually defining how disparate datasets connect, the Santa Clara-headquartered startup said in a statement. These schemas can be used by agents deployed to query enterprise data, giving them a predefined map of how information across different tables and systems is connected, rather than requiring them to identify relevant tables and construct complex SQL joins dynamically, in turn simplifying query generation and reducing errors and retries, it added.

  13. Today's Term

    One new AI word a day, explained simply — it adds up.

    Model Context Protocol (MCP)

    MCP is an open standard, introduced by Anthropic, that lets AI models connect to outside tools and data sources, like a file system, a calendar, or a company database, in one consistent way. Before MCP, every app that wanted to connect an AI model to its data needed its own custom, one-off wiring, similar to every electrical appliance needing a completely different, non-standard plug. MCP is meant to work like a universal power socket: build the connection once, and any compatible AI model can plug in.
