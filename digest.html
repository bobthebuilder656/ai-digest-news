    One new AI word a day, explained simply — it adds up.

    API (Application Programming Interface)

    An API is the standard way one piece of software talks to another. When an app says it's "powered by GPT-4" or "powered by Claude," it usually means the app sends a request over the internet to that AI company's API and gets an answer back, rather than running the model itself. Think of an API as a restaurant menu and waiter: you don't need to know how the kitchen actually works, you just place an order in an agreed format and get the result back.
